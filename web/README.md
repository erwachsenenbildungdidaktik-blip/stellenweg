# Stellenweg

Die App für die Stellensuche: Kompetenzen, Bewerbungsstrategie und Aktionsplan, Dossier, Netzwerk sowie RAV und Arbeitslosenkasse an einem Ort. Alles bleibt auf dem Gerät, nichts wird ins Internet geschickt.

## iPhone / iPad (Web-App)

1. In **Safari** öffnen: https://erwachsenenbildungdidaktik-blip.github.io/stellenweg/
2. Teilen-Symbol → **Zum Home-Bildschirm**
3. Danach läuft die App wie eine normale App, auch offline.

Wichtig: Auf dem iPhone die App unbedingt auf den Home-Bildschirm legen und mindestens einmal pro Woche eine Sicherung machen (Symbol oben rechts im Tab Strategie). Safari kann lokale Daten sonst nach einigen Tagen ohne Nutzung löschen.

## Android

APK herunterladen und installieren: [download/Stellenweg.apk](https://erwachsenenbildungdidaktik-blip.github.io/stellenweg/download/Stellenweg.apk)
(Installation aus unbekannten Quellen erlauben.) Die Android-App kann zusätzlich Apps vom Handy als schwebendes Fenster öffnen, pünktlich erinnern und geteilten Text ins Notizfenster übernehmen.

## Moodle

Den ganzen Ordner als ZIP hochladen und entpacken, `index.html` als Startdatei wählen. Die Bibliotheken liegen im Ordner `vendor/`, die App braucht kein Internet.
